# Neliel curated animation pack

19 clips: Overte animation assets, retargeted to VRM Animation 1.0 by Hanami. Apache-2.0; original copyright (c) 2013–2019 High Fidelity, Inc.; 2019–2021 Vircadia contributors; 2022–2026 Overte e.V. Sources: https://github.com/overte-org/overte and https://github.com/Undi95/Hanami/tree/5cf4afaac1ad8499d0890101a7c93762bf1dc8b0/vrma. Retargeted by the Hanami contributors; copied without binary modification here. See APACHE-2.0.txt.

1 clip: Universal Animation Library by Quaternius (CC0-1.0), converted to VRMA by Ekza Studio: https://github.com/ekza-space/ekza-studio/tree/b7e3e92f25d2656caace50c0869aeef0d562dbf3/apps/web/public/library/animations. Original https://quaternius.com/packs/universalanimationlibrary.html. License https://creativecommons.org/publicdomain/zero/1.0/.

The manifest scripts/neliel-animations.json records exact source revisions, blob hashes and sizes. Build script downloads and validates the files once before bundling; the installed APK works offline for animation playback. No Ready Player Me, Mixamo, Bandai Namco or Rokoko assets included in this pack. Walking loops are preview-only until a navigation system exists. No claim of avatar-specific visual testing.
